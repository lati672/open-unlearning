# muse_books_pilot

Start with REPORT.md. This directory records completed work, not a request to launch new experiments.

The code/ files are byte-identical snapshots of the numerical scripts used in saves/experiments/muse_books_attribute_pilot_v1/code/. Keep the original experiment path when restoring or replaying them; scripts using their parent directory as the experiment root must first be copied there. Do not launch training from this documentation directory.

Full per-example evaluation products, original frozen question/mask contents and training logs remain in the ignored saves/ tree and in the previously verified local result bundles. They are not added to Git. Workstation-specific export helpers containing personal redaction settings are intentionally omitted. ARCHIVE_MANIFEST.json binds every committed snapshot/report to its original bytes. No model weights or credentials are included.
